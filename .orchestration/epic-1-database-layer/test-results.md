## 4. Constraints, Foreign Keys & Cascade Deletion

### 4.1 Foreign Key Definition & Enforcement

- **Constraint Definition**: `PRAGMA foreign_key_list(highlights)` confirmed:
  - `table`: `matches`
  - `from`: `match_id`
  - `to`: `id`
  - `on_delete`: `CASCADE`
- **Orphan Block Test**: Attempting to insert a highlight referencing non-existent match `2026-09-09_faketeama_faketeamb` threw `SQLITE_CONSTRAINT_FOREIGNKEY: FOREIGN KEY constraint failed` as expected. — **PASS**

### 4.2 Cascade Deletion Test

- **Setup**: Inserted parent match `2026-09-09_arsenal_chelsea` with 2 child highlights.
- **Action**: Deleted parent match `DELETE FROM matches WHERE id = '2026-09-09_arsenal_chelsea'`.
- **Verification**: Querying `SELECT COUNT(*) FROM highlights WHERE match_id = '2026-09-09_arsenal_chelsea'` returned `0`. All child highlight records were deleted automatically by SQLite foreign key cascade. — **PASS**
